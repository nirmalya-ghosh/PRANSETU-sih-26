# Contributing to PRANSETU

## Workflow

1. Create a focused branch.
2. Read `AGENTS.md` and relevant docs.
3. Make the smallest coherent change.
4. Build and test.
5. Review the diff.
6. Validate critical behavior on a physical device/service.
7. Open a pull request.
8. Merge only after review and passing checks.

## Commit Style

Prefer concise conventional-style commits, for example:

- `feat: add offline SOS persistence`
- `fix: prevent duplicate relay packets`
- `test: cover SOS retry queue`
- `docs: define IVR protocol`
