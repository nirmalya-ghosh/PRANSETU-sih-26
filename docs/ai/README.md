# PRANSETU Intelligence

## Initial AI capabilities

### Language Intelligence
- language detection
- translation assistance
- multilingual summarization

### Incident Intelligence
- classify incoming reports
- cluster related SOS incidents
- detect duplicates/related events

### Rescue Intelligence
- prioritize incidents using transparent operational factors
- identify vulnerability indicators when explicitly provided

### Cascade Intelligence

Given a confirmed event such as an earthquake, cyclone, flood or landslide, estimate plausible downstream hazards using authoritative inputs and historical/domain knowledge.

The system must present these as forecasts/risk hypotheses with uncertainty, not as guaranteed predictions.

### Situation Summarization

Produce concise operator-facing summaries from structured incident data.

## Safety

AI outputs must not silently replace official warnings, emergency command decisions or authoritative government data. Record model/provider/version metadata for important outputs.
